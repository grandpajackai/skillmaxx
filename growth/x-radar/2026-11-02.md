```
Hi! Following up from X. We install-test agent skills/plugins nightly in clean sandboxes (SkillMaxx).

Grok Build 1.0.62 (1474f9cbdd91), fresh HOME, no credentials:

$ grok plugin marketplace add C-Kapsalis/second-read
Added marketplace source: second-read (https://github.com/C-Kapsalis/second-read.git)
$ grok plugin install second-read --trust
Error: No marketplace plugin named "second-read" in any registered marketplace.
$ grok plugin install second-read@second-read --trust
Error: No marketplace plugin named "second-read" in "second-read".
$ git clone https://github.com/C-Kapsalis/second-read.git sr && grok plugin install ./sr --trust
Installed 1 plugin(s) from ./sr: second-read

So the plugin itself is fine; the marketplace entry doesn't resolve. Our guess is the
"source": "./" (repo root) in .claude-plugin/marketplace.json. Claude Code accepts it;
Grok Build may want a subdirectory. Claude Code and Pi installed clean for us, and
npx skills add drops it into Codex fine.

Happy to re-run after any change.
```
