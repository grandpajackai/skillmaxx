## What SkillMaxx is (in one breath)
A free directory that **install-tests** agent skills, plugins and MCP servers in sandboxes across **Claude Code, Codex, Grok Build, Cursor and Pi**, and shows the exact install command for each agent. 424 entries, 902 sandboxed install tests (803 pass), refreshed nightly. Failures are published, not hidden.

## Who's here
Developers deciding which skill or MCP server to install in their coding agent. That's the moment right before someone adopts your tool.

## The one rule
**Money never changes a test result or a ranking.** Sponsored slots are labeled "Sponsored," always. If your plugin fails a test, the site says so, and we'll happily help you fix it.
